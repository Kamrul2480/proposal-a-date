# Proposal Website ❤️

## Files
- index.html
- style.css
- script.js

## Run on PC
1. Keep all 3 files in the same folder.
2. Double-click `index.html`.
3. The website will open in your browser.

## Publish as a shareable link
You can upload these files to a GitHub repository and enable GitHub Pages.

The site is static, so it does not need a server or database.
